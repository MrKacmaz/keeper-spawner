KeeperSpawner - item spawner for Graveyard Keeper 2
=====================================================

REQUIREMENTS
- BepInEx 5.4.23.5 (win_x64): https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
- Optional: GK2 Mod Framework 0.1.19+ (https://www.nexusmods.com/graveyardkeeper2/mods/42)
  for the in-game Mods menu. KeeperSpawner works without it.

INSTALL WITH GK2 WORKSHOP LOADER
1. Install BepInEx (steps 1-2 of the manual install below).
2. Put GK2_WorkshopLoader.dll (https://github.com/Zoriten/-GK2-WorkshopLoader/releases)
   into Graveyard Keeper 2\BepInEx\patchers\ (not plugins).
3. Subscribe to KeeperSpawner on the Steam Workshop, start the game and click "Yes"
   in the loader's security check.

MANUAL INSTALL
1. Extract BepInEx_win_x64_5.4.23.5.zip next to GraveyardKeeper2.exe.
2. Start the game once and close it (BepInEx creates its folders).
3. Copy the BepInEx folder from this package into the game folder, so that you get:
       Graveyard Keeper 2\BepInEx\plugins\KeeperSpawner\KeeperSpawner.dll
       Graveyard Keeper 2\BepInEx\plugins\KeeperSpawner\KeeperSpawner.GK2Framework.dll
   The second DLL is the optional GK2 Mod Framework bridge. Without the Framework,
   BepInEx skips it ("missing dependencies" in the log); that is expected.
Do not install KeeperSpawner both from the Workshop and manually.

USAGE
- Load a save and press the letter O (not zero) to open the spawner. The key can be
  changed in the config or, with GK2 Mod Framework, in Mods > KeeperSpawner > Settings.
- Click: add the amount chosen under "Click" (1 / 10 / Max). Shift+Click: add 1.
- Right-click: add or remove a favorite. Ctrl+F: search. Esc: close.

SETTINGS
  BepInEx\config\com.mrkacmaz.keeperspawner.cfg (created after the first start)

UNINSTALL
  Delete Graveyard Keeper 2\BepInEx\plugins\KeeperSpawner (or unsubscribe in the loader).

LOG
  Problems are written to Graveyard Keeper 2\BepInEx\LogOutput.log.
  "KeeperSpawner 1.1.0 loaded" means the mod started.


KeeperSpawner - Graveyard Keeper 2 için item spawner
=====================================================

GEREKSİNİMLER
- BepInEx 5.4.23.5 (win_x64): https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
- İsteğe bağlı: oyun içi Mods menüsü için GK2 Mod Framework 0.1.19+
  (https://www.nexusmods.com/graveyardkeeper2/mods/42). KeeperSpawner onsuz da çalışır.

GK2 WORKSHOP LOADER İLE KURULUM
1. BepInEx'i kur (aşağıdaki elle kurulumun 1-2. adımları).
2. GK2_WorkshopLoader.dll dosyasını (https://github.com/Zoriten/-GK2-WorkshopLoader/releases)
   Graveyard Keeper 2\BepInEx\patchers\ klasörüne koy (plugins değil).
3. Steam Atölyesi'nde KeeperSpawner'a abone ol, oyunu aç ve loader'ın güvenlik
   penceresinde "Evet"e bas.

ELLE KURULUM
1. BepInEx_win_x64_5.4.23.5.zip dosyasını GraveyardKeeper2.exe'nin yanına çıkar.
2. Oyunu bir kez açıp kapat (BepInEx klasörlerini oluşturur).
3. Bu paketteki BepInEx klasörünü oyun klasörüne kopyala; sonuç şöyle olmalı:
       Graveyard Keeper 2\BepInEx\plugins\KeeperSpawner\KeeperSpawner.dll
       Graveyard Keeper 2\BepInEx\plugins\KeeperSpawner\KeeperSpawner.GK2Framework.dll
   İkinci DLL isteğe bağlı GK2 Mod Framework köprüsüdür. Framework yoksa BepInEx onu
   atlar (logda "missing dependencies"); bu normaldir.
KeeperSpawner'ı hem Atölye'den hem elle kurma.

KULLANIM
- Bir kayıt yükle ve spawner'ı açmak için O harfine bas (sıfır değil). Tuş ayar dosyasından
  ya da GK2 Mod Framework ile Mods > KeeperSpawner > Settings'ten değiştirilebilir.
- Tık: "Tık" altında seçili miktarı ekler (1 / 10 / Maks). Shift+Tık: 1 adet ekler.
- Sağ tık: favorilere ekler/çıkarır. Ctrl+F: arama. Esc: kapat.

AYARLAR
  BepInEx\config\com.mrkacmaz.keeperspawner.cfg (ilk açılıştan sonra oluşur)

KALDIRMA
  Graveyard Keeper 2\BepInEx\plugins\KeeperSpawner klasörünü sil (ya da loader'da aboneliği bırak).

LOG
  Sorunlar Graveyard Keeper 2\BepInEx\LogOutput.log dosyasına yazılır.
  "KeeperSpawner 1.1.0 loaded" satırı modun başladığını gösterir.
